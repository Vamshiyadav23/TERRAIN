
# TERRAIN

## AI-Driven Satellite Image Change Intelligence System

TERRAIN is an AI-assisted geospatial intelligence platform for detecting, quantifying, interpreting, and visualizing temporal changes in satellite imagery.

### Core Pipeline

Sentinel-2 Acquisition
→ Multispectral Preprocessing
→ Spectral Change Detection
→ Change Region Extraction
→ Spatial Zone Grouping
→ Quantitative Evidence
→ Qwen 2.5-VL Semantic Interpretation
→ Geospatial Visualization
→ Explainable Change Intelligence
